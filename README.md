Formica rufa habitat suitability model for Wales

MRes Biodiversity and Ecosystems, Swansea University
Author: Vianney Foglizzo
Supervisors: Wendy Harris, Jim Bull

Overview
This repository contains R scripts used to build a MaxEnt habitat suitability model for the red wood ant (Formica rufa) in Wales at 30 m resolution, following the methodology of Robinson et al. (2024). 
Output rasters are available on Zenodo: https://doi.org/10.5281/zenodo.23487872.

R packages: terra, tidyverse, ENMeval, dismo, rJava, sf, tidyterra
